# GeometryAI

Простой **ИИ-проходитель Geometry Dash** на Python c **авто-подстройкой**.

## Что умеет
- Симулирует движение куба по 1D-уровню с физикой прыжка.
- Избегает опасных сегментов (шипы/ямы) на земле.
- Ищет безопасную последовательность действий `RUN/JUMP` до финиша.
- Если базовые параметры не подходят, автоматически перебирает набор конфигураций
  (таймстеп, дискретизацию и параметры физики), чтобы найти проходимый маршрут.

## Быстрый старт
```bash
python3 geometry_dash_ai.py
```

## Как настроить свой уровень
Отредактируйте `demo_level()` в `geometry_dash_ai.py`:
- `length` — длина уровня.
- `hazards` — список опасных отрезков `Hazard(start, end)`.
- Базовые параметры: `gravity`, `speed`, `jump_velocity`.

## Идея алгоритма
- Состояние: `x`, `y`, `vy`, `on_ground`.
- На каждом тике ИИ выбирает действие: `RUN` или `JUMP`.
- Поиск пути: Dijkstra по дискретным состояниям.
- Над поиском работает слой `AdaptiveGeometryDashAI`: он пробует несколько
  конфигураций и выбирает первую, которая дает успешный проход.
